# Using Student Tags in Smart Grouping

## Working Summary

Use Tag Balancing when you want ClassSeats to consider student tags while it creates groups. Tags can help you spread certain students across tables, build groups around shared interests, or create a more thoughtful mix of support needs and peer leaders.

Tag Balancing is best-effort. ClassSeats will try to follow your tag rules while still respecting the group size, table choices, and other grouping settings you choose. After groups are generated, review them and make any teacher judgment changes you need.

## Before You Start

Tag Balancing works with the student tags already saved in your class.

Before generating groups, create or assign the tags you want to use. You can do that from an individual student card, the Tag Matrix, or while importing students.

Then go to the **Groups** tab, choose your grouping settings, turn on **Table Tag Balancing**, and click **Add Rule**.

## Example 1: Spread Chatty Students Across Groups

If a few students tend to pull each other off task, create a tag such as **Chatty** and use **Spread evenly**. ClassSeats will try to avoid placing too many students with that tag at the same table.

This can be helpful when students are still able to work with anyone, but you want to avoid accidentally creating one very talkative group.

In this example, **Needs Support** and **Peer Leader** are used together. ClassSeats can use those tags to create groups that are more balanced for classroom work.

## Final Tip

Tags are a starting point, not a replacement for your knowledge of students. If a generated group needs a quick change, drag students where they need to go, then save the groups when they look right.
